Privacy policy

Privacy

Thousand Turns is personal, local software. It does not run a server, collect analytics, set cookies or share your data with anyone. This page explains exactly what it reads, where it is kept and how to delete it.

Effective 15 November 2026

1. Who this applies to

This policy covers the Thousand Turns application — the locally installed video studio and its command-line tools — and this website. The application is operated by its owner on their own computer for their own YouTube channel. It is not a public service and has no user accounts.

2. What the application accesses

Only after you sign in or provide a token, and only through the platforms' official APIs:

  • YouTube Data API — your channel's public uploads, titles, descriptions, durations and public statistics; public comments and replies on those videos; public search results used for topic research.
  • YouTube Analytics API — your channel's own analytics: views, watch time, retention, impressions where available, traffic sources, audience geography and demographics, subscriber changes, search terms.
  • YouTube upload — only when you run the publish command. The application sends the video file and the title, description, tags, thumbnail and privacy setting you approved.
  • Instagram API (Instagram Login) — your own media list and insights, account-level audience insights, and publishing a Reel when you explicitly run the publish command with a public video URL.

The application does not read other people's private data, direct messages, passwords or payment details.

3. Where the data is stored

  • Credentials (OAuth tokens and API keys) are stored only on your computer, in ~/.video-maker/secrets/, with file permissions restricted to your user account.
  • Analytics snapshots, reports and render files are stored in your own project and channel folders on the same computer.
  • Nothing is uploaded to the application's author. There is no backend, database or telemetry endpoint.

4. Sharing

No data is sold, rented or shared with third parties. The only network requests are the ones you trigger, made directly from your computer to Google/YouTube or Meta/Instagram. Those companies handle the data under their own privacy policies. This website uses no analytics, advertising, cookies or third-party scripts.

5. Retention and deletion

  • Delete a token: remove the corresponding file in ~/.video-maker/secrets/.
  • Delete analytics: remove the analytics/ folder in the channel folder.
  • Delete everything: remove the project and channel folders, then ~/.video-maker/.
  • Revoke the platform's access without deleting files: Google account permissions or the Instagram app settings.

Because the application stores data only on your machine, deleting those files is complete deletion.

6. Children

The application is not directed to children and is not used to collect data from them. It is a production tool for its owner's channel.

7. Security

Credentials are kept in a user-only directory and are never printed in logs or committed to version control. Network requests use HTTPS. No system is perfectly secure; if you believe a credential has leaked, revoke it at the platform and create a new one.

8. Changes

If this policy changes, the effective date above changes with it. The current version is always at this address.

9. Contact

Questions or a deletion request: open an issue.
